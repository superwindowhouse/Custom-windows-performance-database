# Tilt and Turn Window Engineering Performance Specification

## Overview
A dual-function, multi-point locking window system providing inward tilt from the top for secure ventilation and full side-hinged inward swing for cleaning and emergency egress.

## Performance Parameters

| Parameter | Specification |
|-----------|---------------|
| Air Leakage (ASTM E283) | 0.01–0.05 cfm/ft² |
| U-Value (NFRC 100) | 0.18–0.28 Btu/h·ft²·°F |
| Design Pressure (DP) Rating | 40–60 |
| STC (Acoustic Insulation) | 35–40 |
| Locking Points | 6–12 points per sash perimeter |

## Material Configuration
- Frame materials: uPVC (vinyl), aluminum-clad wood, thermally broken aluminum.
- Fiberglass reinforcement available for large openings.
- Steel multi-point locking hardware concealed within frame perimeter.
- Compression gaskets for sash-to-frame seal.
- Factory-installed perimeter sealant tape and integrated sill pans (optional).

## Structural Characteristics
- Multi-axis switching mechanism: single handle reconfigures hinge engagement for tilt mode (bottom hinges locked, top pivots inward) vs. turn mode (side hinges unlocked, full inward swing).
- Block-and-shim installation method with continuous sill pan and exterior flashing; window fastened through frame into rough opening.
- Concealed steel locking rods and gearbox eliminate thermal bridging.
- Sash pressed against compression gaskets in locked mode; wind load distributed across frame.

## Applicable Standards
- ASTM E283 (air leakage test)
- NFRC 100 (U-factor)
- IBC (egress compliance in turn mode)
- ASHRAE 62.1 (natural ventilation)
- TAS 201/202 (hurricane impact test, with laminated glass and reinforced frames)
- Miami-Dade (impact-rated models available)

## Engineering Notes
- Handle positions: down = locked; sideways = turn mode (full swing); up = tilt mode (top pivot).
- In tilt mode, opening gap 4–6 inches prevents intrusion and rain entry; allows child-safe ventilation without secondary locks.
- Turn mode enables interior cleaning of both glass surfaces without exterior access equipment.
- Three operating modes reduce fenestration types required (replaces picture, casement, and hopper windows).
- Multi-point locking compresses weatherstripping evenly, eliminating drafts and reducing sash warpage.
